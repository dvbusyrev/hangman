# Настройки прототипа

Все основные визуальные и навигационные параметры находятся в `public/data/config.json`.
Изменения подхватываются после обновления страницы; OSM-файлы повторно скачивать не нужно.

## Камера регионов

`map.initialCamera` — стартовая камера над Арктикой.

`map.regionViews.<regionId>` — камера после выбора региона:
- `height` — приближение: меньше значение = ближе;
- `offsetLon` — сдвиг по долготе: `+` вправо/на восток, `-` влево/на запад;
- `offsetLat` — сдвиг по широте: `+` вверх/на север, `-` вниз/на юг;
- `heading` — поворот камеры;
- `pitch` — угол наклона (`-90` строго сверху).

## Камера прогулки

`navigation`:
- `cameraHeightMeters` — высота глаз над землёй;
- `cameraPitchDegrees` — угол подъёма/наклона камеры (`0` горизонтально);
- `fieldOfViewDegrees` — угол обзора;
- `roadStepMeters` — расстояние между точками маршрута;
- `wheelDivisor` — скорость движения колёсиком. Чем БОЛЬШЕ число, тем МЕДЛЕННЕЕ движение;
- `maxWheelStepsPerEvent` — ограничитель резкого скролла;
- `cardTriggerDistanceMeters` — расстояние появления карточки;
- `cardHideBehindDegrees` — когда дом считается пройденным и карточка исчезает;
- `cardAnchorHeightFactor` — на какой высоте фасада привязывать указатель карточки.

Для отдельного города значения можно переопределить в `cityOverrides.<cityId>`.

## Высоты домов

`buildings` задаёт разные диапазоны для:
- `residential` — многоквартирные/жилые здания;
- `house` — малоэтажные дома;
- `industrial` — промышленные;
- `nonResidential` — офисы, магазины, школы и другие нежилые;
- `unknown` — здания с неопределённым типом OSM.

Если в OSM есть `building:levels`, число этажей используется в первую очередь.
Для остальных зданий высота детерминированно генерируется в диапазоне соответствующего класса,
поэтому при перезапуске один и тот же дом не меняет высоту.

## Текстуры

По умолчанию используется процедурная сетка фасада из `buildings.facadeGrid`. Она стабильнее для
экструдированных Cesium-полигонов: обычный `ImageMaterial` часто заметно растягивается и ложится
на здания не как фасадная текстура.

`buildings.useImageTextures = true` включает старый режим с картинками из `buildings.textures`.
Все текущие SVG лежат в `public/textures/` и работают офлайн.

## Карта под ногами

`basemap.cityOfflineRaster = true` включает локальную OSM-подобную карту, которая во время запуска
рисуется из уже скачанных `*-roads.geojson` и `*-buildings.geojson`. Отдельные линии дорог в Cesium
больше не создаются. Интернет в 3D-городе для этой подложки не требуется.
